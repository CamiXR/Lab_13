## Что делает
Программа хранит стримеров в файле data.txt:
создаёт объекты класса Streamer, сохраняет их и загружает обратно.
Обрабатываются ошибки: деление на ноль, неверный ввод,
отсутствующий файл, неверный формат данных.
 
## Как запустить
python main.py
(На Ubuntu: python3 main.py)
